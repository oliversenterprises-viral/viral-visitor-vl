# Compliance & Brand Safety — ViralRefer 2026 Campaign

## Every public promotion must include

- [ ] US residents **18+** eligibility
- [ ] **No purchase necessary** (where contest/prize mentioned)
- [ ] Link to **full official rules**
- [ ] Skill-based / contest disclaimers as applicable
- [ ] No guarantee of earnings or ranking outcome

## Claims review

- [ ] Leaderboard mechanics described accurately
- [ ] Prize amounts and verification steps match live copy
- [ ] "Free" and "no signup" claims are true for link generation
- [ ] Testimonials only with consent or clearly hypothetical

## Platform rules

- [ ] Reddit: value-first, subreddit rules checked, no spam
- [ ] X: no misleading engagement bait; authentic account @viralrefer
- [ ] Meta/paid: **only if user confirms compliant ad account**
- [ ] Email: CAN-SPAM basics if list used

## Crisis protocol

1. Pause all amplification
2. Document issue source
3. Draft transparent response
4. Resume only after user approval
